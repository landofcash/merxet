Connect your shop namespace

One-time setup for ENSv2 on Ethereum Sepolia. Use the administrator wallet that owns the parent name.

The backend receives permission to register subnames. The administrator retains control of the parent and registry. Each shop gets its own resolver with permission for the backend to update only that shop's URL.

Set up Merxet for your AI assistant

Merxet AI-assisted ordering is an MVP pilot for Hedera testnet testing. Mainnet ordering is not available.

The official Merxet integration runs locally. It can prepare and track an order, but it cannot access your wallet or approve payment. You always review and approve the transaction in the official Merxet app.

Claude Desktop for Windows

This first pilot bundle is unsigned and has been prepared for Windows. Claude Desktop may show a warning during installation. Only install a bundle downloaded from this Merxet page.

Download Merxet for Claude

View the SHA-256 checksum

  1. Download the Merxet MCP Bundle above.
  2. Open Claude Desktop and go to Settings, then Extensions.
  3. Open Advanced settings, choose Install Extension, and select the downloaded merxet-1.0.0.mcpb file.
  4. Review the testnet pilot notice and finish the installation.
  5. Restart Claude Desktop if Merxet does not appear immediately.

Codex

  1. Make sure Codex and Node.js 22 or later are installed.
  2. Open a terminal and run:
codex mcp add merxet -- npx -y @merxet/mcp@1.0.0

Confirm that Merxet is connected:

codex mcp list

Restart Codex if the Merxet tools do not appear immediately.

Other local MCP applications

Merxet uses the standard local STDIO transport. In an application that supports local Node.js MCP servers, use: 

Command: npx
Arguments: -y @merxet/mcp@1.0.0

Other applications have not yet completed the Merxet testnet pilot acceptance flow. Follow the MCP setup instructions supplied by your application.

Ask for an order

Order one can of sardines from this Merxet catalogue: https://promo.merxet.com. Ask me for the delivery details and send me the link to review and approve.

Your assistant should show you the actual item and price before it creates the approval link. Payment is completed only after you review the transaction in the Merxet browser app.

Set up Merxet for Codex

Merxet AI-assisted ordering is an MVP pilot for Hedera testnet testing. Mainnet ordering is not available.

The Merxet integration runs locally in Codex. It can prepare and track an order, but it cannot access your wallet or approve payment. You always review and approve the transaction in the official Merxet app.

Connect the integration

  1. Make sure Codex and Node.js 22 or later are installed.
  2. Open a terminal and run:
codex mcp add merxet -- npx -y @merxet/mcp@1.0.0
  1. Confirm that Merxet is connected:
codex mcp list
  1. Restart Codex so the Merxet integration becomes available.
  2. Return to the catalogue and ask Codex to help with your order.

Example request

Please order one can of sardines from https://promo.merxet.com. Ask me for the delivery details you need, then send me the Merxet link to review and approve the payment.

For AI agents

Open the machine-readable Merxet catalogue

Catalogue descriptor: https://sync.merxet.com/api/v1/t/catalogs/seed/{catalogSeed}

Resolve catalogSeed from the first URL path segment, then ?seed=, or use the default promo catalogue. Fetch the testnet descriptor and follow its catalogUrl to discover exact ProductId values.

Ordering availability: Agent-assisted ordering is an MVP pilot for Hedera testnet testing only. Mainnet ordering is not available. Do not attempt to create an order for a mainnet catalogue.

To prepare an order, check whether the Merxet MCP tool create_merxet_order is available. If it is unavailable, tell the user that Merxet MCP must be connected. Do not claim that an order or x402 quote was created.

Links labelled "Open in app" are ordinary human storefront links, not signed x402 approval links.
